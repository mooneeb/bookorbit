# Native fixed-page appearance and animation preferences

Production PDF and comic readers now expose Reader settings with explicit Cancel, Save for this book, Save as defaults, and Use defaults actions. PDF controls apply fit-page/fit-width/automatic/custom zoom and display rotation without rewriting source PDF pages. Comic controls apply fit-page/fit-width/fit-height/decoded actual size and black/gray/white page backgrounds, with native pinch zoom bounded to four times the decoded image size. Defaults and per-file choices are stored separately for each server, account and format, with a 16 KiB limit per stored value.

Five native page animations are implemented: UIKit page curl, horizontal slide, vertical slide, fade, and immediate changes. Reduce Motion selects immediate changes. Both reader surfaces share a bounded native paging controller; current and adjacent controllers are retained, and superseded fade completions cannot remove a newer page. The current logical PDF/comic page remains owned by the existing acknowledged progress models when preferences or motion settings change. PDF now also offers explicit Previous/Next and keyboard arrows for the immediate/fade paths.

The existing account `syncReaderPreferences` setting controls appearance synchronization. Native layout/animation stays on the device. Synchronized changes PATCH only changed owned appearance fields, preserving unrelated web preferences and concurrent changes to other fields. Global defaults and the current book acknowledge separately; feedback identifies a saved global default when the book update fails, while preserving the draft. Using defaults unsets only the native-owned look fields. Restricted demo accounts cannot mutate synchronized preferences. Failed loads require Reload settings before Save; remote values are validated before renderer application.

Shared request/response projections and generated models come from `reader-settings.ts`. PDF/comic built-in defaults are generated from the canonical constants, including constant references, rather than copied into Swift. Sparse legacy defaults can omit later fields. Source PDF rotation remains unchanged because rotation affects the display view only.
