## Full editor payload and omission rules

Send changed fields only. Omission preserves existing data; supported scalar `null` explicitly clears it. Do not encode every absent Swift optional as JSON null. The web takes a loaded snapshot, calculates changes and sends the combined metadata/locks route. The working-tree canonical shared request now includes title/subtitle/description, publication fields, ISBNs and author/genre/tag name arrays; it remains a partial editing contract. For the complete wire fields, follow `UpdateBookMetadataDto` and its nested DTOs, with canonical shared response/domain types. [Web payload builder:251](https://github.com/mooneeb/bookorbit/blob/5c56bb4bab256f5855e6f26e053b13d52ee6147a/client/src/features/book/composables/useMetadataEditor.ts#L251-L336), [shared payload](../packages/types/src/book.ts).

| Field family      | Wire contract and important limits                                                                                                                                                                                                                                                                                                                              |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Text/date/number  | Title/subtitle max 1000 characters; description string; publisher max 500; language max 100. `publishedDate` is a real `YYYY-MM-DD` date, year integer 1000 to 2200. A nonnull date determines year; a year-only update clears date. Page count integer at least 1; incoming zero becomes null. Personal rating integer 1 to 5 or null.                         |
| Identifiers       | `isbn10` max 10 and `isbn13` max 13. Provider fields are `googleBooksId`, `goodreadsId`, `amazonId`, `hardcoverId`, `hardcoverEditionId`, `openLibraryId`, `itunesId`, `audibleId`, `librofmId`, `koboId`, `comicvineId`, `ranobedbId`, `lubimyczytacId`, `aladinId`. These are individual PATCH keys, not a `providerIds` object. Lengths vary from 20 to 512. |
| Lists             | Authors/genres/tags use arrays of names, not IDs or comma-separated strings. `[]` clears that entire relation. Avoid null for these arrays: service code calls array methods directly.                                                                                                                                                                          |
| Series            | Prefer `seriesMemberships: [{seriesName,seriesIndex,expectedBookCount}]`, a complete replacement; `[]` or null clears. This supersedes legacy seriesName/index when present. Index is a decimal string matching `^\d+(?:\.\d+)?$`, max 20 characters. Expected count is 1 to 10000 or null and changes a shared series total across books/users.                |
| Community ratings | Complete replacement `[{provider,rating,ratingCount}]`; rating may be fractional 0 to 5, count nonnegative integer or null. Do not send response-only `updatedAt`. `[]` or null clears. Distinct from personal rating.                                                                                                                                          |
| Audio             | Nested `audioMetadata: {narrators:string[],durationSeconds:int>=0 or null,abridged:boolean or null,chapters:[{title,startMs:int>=0,durationMs:int>=0 or null}] or null}`. Omitted nested fields preserve values; narrators `[]` clears; null abridged becomes false. A null whole audioMetadata object does not clear its fields.                               |
| Comic             | Nested `comicMetadata` with issueNumber max 50, volumeName max 500, and string-array pencillers/inkers/colorists/letterers/coverArtists/characters/teams/locations/storyArcs. Use null for nullable text and `[]` for lists. Omit untouched fields.                                                                                                             |
| Custom            | `customMetadata: [{fieldId,value}]` is a patch by field ID, not complete replacement. Empty array changes nothing. Null value removes one stored value.                                                                                                                                                                                                         |

Extra wire keys fail global whitelist validation. Covers, added date, personal notes and chapters flattened at root are not ordinary metadata fields. Added date and personal note have separate PATCH routes. [Book controller](../server/src/modules/book/book.controller.ts).

Custom controls can use `BookDetail.customMetadata`, which already includes every enabled field for that library, ordered and with null for empty values. Types are `text`, `url`, `number`, `date`, `boolean`. Text is trimmed; URLs require http/https; numbers must be finite; dates are real ISO date keys; boolean false and numeric zero must survive. The service also accepts numeric strings and literal boolean strings, but native controls should send typed JSON. Archived/disabled/unknown field IDs reject updates. Definition creation sends `{label,type,displayOrder?,enabledLibraryIds?}`; updates cannot change type/key. Archive, restore and permanent deletion are separate 204 routes. These are admin workflows, distinct from editing a book's custom values. [Custom types](../packages/types/src/custom-metadata.ts), [value service:146](https://github.com/mooneeb/bookorbit/blob/5c56bb4bab256f5855e6f26e053b13d52ee6147a/server/src/modules/custom-metadata/custom-metadata.service.ts#L146-L207), [normalization:288](https://github.com/mooneeb/bookorbit/blob/5c56bb4bab256f5855e6f26e053b13d52ee6147a/server/src/modules/custom-metadata/custom-metadata.service.ts#L288-L351), [definition DTOs](../server/src/modules/custom-metadata/dto/).

## Matching and comparison behavior to preserve

Use authenticated streaming HTTP, with cancellation and separate handling of named provider-status events. The web uses fetch rather than EventSource. Explicit provider lists still exclude globally disabled providers; `mediaKind` narrows eligible providers. Book-context search otherwise uses effective field-rule providers. Query limits are title 500, author 255, ISBN 30. [Search controller](../server/src/modules/metadata-fetch/metadata-fetch.controller.ts), [web stream](../client/src/features/book/composables/useMetadataSearch.ts).

Comparison is a client decision workspace. Existing provider-ID or normalized ISBN agreement yields a strong match; same core title plus author agreement yields possible; remaining results are weak. Ordering then considers score, configured provider order and arrival. Preserve the active candidate, field picks from other candidates, current/proposed values, locked rows, fill-empty/take-all/clear operations, genre merge versus replacement, and provider-specific community rating picks. Applying choices stages the editor draft and closes the drawer; it does not immediately save. Candidate identity is `provider:providerId`. Every provider contributing a chosen value is linked through its corresponding identifier field unless locked; existing unrelated provider IDs are preserved. [Ranking source](../client/src/features/book/lib/metadata-match.ts), [diff classification](../client/src/features/book/lib/metadata-diff-fields.ts), [decisions and patch](../client/src/features/book/composables/useMetadataDiff.ts), [drawer apply](../client/src/features/book/components/detail/tabs/MetadataSearchDrawer.vue).

For mixed ebook/audio books the web runs a second search for the other cover medium using title/author and medium, deliberately omitting the main edition's ISBN. Use the selected slot's `cover` or `audioCover` lock. A take-all action avoids wrong-shape artwork when a cover already exists, while an explicit cover choice can choose it. Preview autofill likewise stages values, honors draft locks and displays diagnostics for an empty/interrupted result. [Second-medium search:129](https://github.com/mooneeb/bookorbit/blob/5c56bb4bab256f5855e6f26e053b13d52ee6147a/client/src/features/book/components/detail/tabs/MetadataSearchDrawer.vue#L129-L142), [diff cover choices](../client/src/features/book/composables/useMetadataDiff.ts), [web editor](../client/src/features/book/components/detail/tabs/EditMetadataTab.vue).

| Operation                 | Contract                                                                                                                                                                                                                                                                       |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Search                    | `GET /books/cover/search?title=...&author=...&isAudiobook=true&provider=...`. | Preview image             | Search results include a rewritten relative `previewUrl` through `GET /books/cover/proxy?url=...`; decode image bytes and use the normal authenticated API base. `sourceUrl` is attribution; selected `url` is the upload source.                                              |
| Upload selected file      | `POST /books/:id/cover?medium=ebook` or `medium=audio`, multipart part `file`, appropriate `image/*` MIME. Returns 204 with no JSON. Production multipart limit is 20 MiB; image bytes must decode successfully.                                                               |
| Upload selected URL       | `POST /books/:id/cover/from-url?medium=...`, JSON `{url}`. Returns 204. HTTP/HTTPS URL with a TLD; URL and each redirect are checked for private/local addresses. | Revert                    | `DELETE /books/:id/cover?medium=...` returns `{coverSource:"extracted"}` or `{coverSource:null}`. ## File outcomes and deterministic public-boundary checks

Metadata persistence commits before the synchronous file outcome. Report “metadata saved, file write failed/skipped” separately from request/save failure. `write:null` means no immediate outcome; it does not prove writing. The web distinguishes success, skipped and failed with the reason. Use `BookDetail.fileWriteStatus` and `getBookFileWriteFormatFields` for meaningful availability; custom values and every metadata field are not writable to every format. Cover changes schedule automatic writing and expose no immediate write result. [Post-save flow:1910](https://github.com/mooneeb/bookorbit/blob/5c56bb4bab256f5855e6f26e053b13d52ee6147a/server/src/modules/book/book.service.ts#L1910-L1999), [web result messages:691](https://github.com/mooneeb/bookorbit/blob/5c56bb4bab256f5855e6f26e053b13d52ee6147a/client/src/features/book/components/detail/tabs/EditMetadataTab.vue#L691-L712), [format capabilities](../packages/types/src/file-write.ts).

## Native image selection and bounded upload

Apple recommends file representations when transferring large images. The imported file URL belongs to the transfer and must be copied before retaining it. The native editor imports inside the file-representation closure and copies the selected file into its own temporary storage. It preserves that artifact for upload and separately produces a 400-pixel PNG preview. Imported bytes and delivered cover bytes are capped at 20 MiB; preparation runs on a serial actor. The previous 2,048-pixel JPEG preparation lost resolution and transparency and was rejected by review and the large-image native tracer. Corrected native Save/relaunch and browser rendered/delivered-alpha checks passed; see the run-32303 evidence in [verification.md](verification.md). [FileRepresentation](https://developer.apple.com/documentation/coretransferable/filerepresentation), [PhotosPickerItem](https://developer.apple.com/documentation/photosui/photospickeritem).

ImageIO supplies the original pixel dimensions and detected format without requiring a full-size display bitmap. The detected uniform type supplies the multipart MIME type; the original input filename is not embedded in request headers. PNG preview encoding preserves alpha while the upload artifact retains its original encoding. [Image sources](https://developer.apple.com/documentation/imageio/cgimagesource), [uniform type MIME type](https://developer.apple.com/documentation/uniformtypeidentifiers/uttype-swift.struct/preferredmimetype).

The request body is assembled into an owned temporary file with bounded 64-KiB copies. URLSession uploads from that file, so the native multipart operation does not build another full encoded body in memory. The selected preview remains staged until the authenticated 204 response and public detail refresh succeed. Files are removed on discard, success, cancellation or closing the editor. Native session generation and same-origin authentication guards cover upload and versioned image delivery. [URLSession upload from file](<https://developer.apple.com/documentation/foundation/urlsession/upload(for:fromfile:delegate:)>). Runtime results and remaining limitations are recorded in [verification.md](verification.md).
