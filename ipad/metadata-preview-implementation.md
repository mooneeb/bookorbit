# Automatic and embedded metadata comparison

The native metadata editor now offers Preview automatic metadata and Compare metadata from file. Automatic preview uses the existing authenticated `POST /books/:id/refresh-metadata?preview=true` route and displays provider diagnostics. Embedded comparison uses `GET /books/:id/metadata-from-file` and reads the primary file without writing it. Both operations use the existing server ownership and metadata permission checks.

Available values appear beside the current draft. Each field requires explicit selection; locked fields remain disabled and locks are checked again when applying. Cancel leaves the draft unchanged. Apply changes only the draft, and the existing Save action persists the selected changes. Automatic ebook and audio cover selections are independent and retain the existing separate cover acknowledgment and partial-failure behavior.

The shared package now owns the embedded-file response contract used by the server, web client and generated native models. Native decoding distinguishes an absent field from an explicit null. Offered clears, empty lists, zero numbers and false booleans therefore retain their meaning. Embedded comic issue and volume fields preserve the actual nullable response. Comparison includes publication date/year, provider identifiers, series, enabled custom fields, comic metadata and available audio fields. Series expected counts remain unchanged when the preview does not offer them.

Preview requests retain at most 1 MiB of JSON, have a two-minute request timeout, cancel on dismissal and reject stale sessions. Comparisons allow at most 1,024 distinct fields. Cover previews reuse the authenticated bounded image loader. No complete library, publication download, migration or new provider protocol is introduced.

Shared types, production server typechecking, web typechecking, full server and client ESLint, generated-contract freshness, strict handwritten Swift formatting and production Swift 6 compilation pass. Logs are `/tmp/bookorbit-metadata-preview-corrected-server-typecheck.log`, `/tmp/bookorbit-metadata-preview-final-client-typecheck.log`, `/tmp/bookorbit-metadata-preview-final-server-eslint.log`, `/tmp/bookorbit-metadata-preview-final-client-eslint.log` and `/tmp/bookorbit-metadata-preview-final-build.log`. The native build retains the existing OIDC initializer deprecation and AppIntents metadata warnings. Earlier failed contract checks are preserved separately.

Independent public HTTP/native/browser/file testing is the next handoff. Required acceptance includes explicit null versus omission, locks, permissions and identity isolation, canceled or failed requests, unchanged draft/file state before Save, independent cover acknowledgment, cross-client reopen and full unfiltered accessibility audits. Actual screenshots must be inspected; source checks do not establish runtime acceptance or human-reviewed visual baselines.
