`N`, `W`, `H` in the action table mean currently discoverable native XCUITest, real-browser test and public HTTP/artifact test. Their links identify exact source entry points. An action mapping inherited from the audit means a public selector or label candidate was found; it does **not** establish that the whole action or its outcome is asserted. `none` means no exact current source match was found in the inspected catalog, including historical tests now absent from the checkout. Every action row remains open.

Authored test source, implementation reports, builds, screenshot capture, isolated phase passes, human walkthrough and physical proof have separate status. No historical run is promoted to current-source acceptance. Hardware/protocol fixtures prove downstream state only; they cannot prove sensor input, live credentials or signing renewal. ## Runnable commands

Run from repository root with Node >=24, pnpm >=9, Docker PostgreSQL and the documented Xcode/iPad simulator prerequisites:

```sh
pnpm ipad:contracts:check
pnpm ipad:test:http
pnpm ipad:test:cross-client
pnpm ipad:test:pdf-reader
pnpm ipad:test:reader-cross-client
pnpm ipad:test:e03:list
pnpm ipad:test:e03
pnpm ipad:test:e03:ui
pnpm ipad:test:e03:web
node scripts/ipad/e03-visual.mjs
```

Native selection uses `IPAD_TEST_ONLY=BookOrbitUITests/<Class>/<method>` with the owning harness command. E02 commands/profiles are documented in its linked test plan. E03 case selection uses `--e03-case=A01` through `A05`. E05 runner source is [`scripts/ipad/e05-runner.mjs`](../../scripts/ipad/e05-runner.mjs); use its owning test plan for runnable fixture/build commands. This document does not invent an E04 package script. Run reports belong in `test-results/ipad/<runID>` with fixture/environment manifests, logs, `.xcresult`, browser reports/traces, artifacts and inspected actual/expected/diff images. Protect private runtime environment files.
