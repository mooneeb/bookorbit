# Technical fault and operational acceptance

Implementation gates for the final [acceptance index](README.md), assembled from confirmed contracts for [Agree the complete reading journey and build-readiness criteria](https://github.com/mooneeb/bookorbit/issues/13). These are future checks, not runtime results. They add no new product policy; their linked owners define exact contracts, limits and recovery rules.

Every row initializes its own account/server/source data, clients, operations and expected revisions/assets. Do not borrow state or a result from another row. For each named fault boundary/variant, run independently and record the actual injection point, acknowledged state, current heads, asset digests, durable receipts and observable result. The control condition and human workflow must work before interpreting a fault outcome. Report Pass, Fail or Blocked per variant; a retry cannot erase evidence from an earlier failed run.

Use isolated deployments, generated/private test copies, clean restore targets and a second owner for permission checks. No personal server, account, app container, certificate or source is altered by this planning document. Keep secrets, note bodies and full paths out of public artifacts. Stable fixture identities and sanitized evidence are sufficient for public summaries.

| Cancel or run out of space during preparation | Initialize valid downloads/notes; independently cancel transfers, change source during preparation and exhaust permitted staging space before a complete save. | Verified completeness/source checks, explicit retry/space state and the accepted one-GiB reserve; protected work/chosen downloads survive, incomplete books are not Ready offline. [Space policy][space], [bounds][storage-bounds].        |

## Packaging, device continuity and scale

| Case                                             | Fresh setup and controlled variation                                                                                                                                                 | Required result and policy owner                                                                                                                                                                                                                                         |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Verify the actual production package             | Inspect the chosen build's entitlements, slots/AppIDs, deployment/runtime/content versions, exact bundled vendor hashes, provenance and license/notice inventory.                    | Supported free route/identity and dependency pinning are concrete. Missing notices/provenance or unsupported runtime capability blocks release rather than silently changing the selected stack. [Package contract][packaging].                                          |
| Renew/update and recover migration failure       | Independently exercise production manual renewal, controlled update and supported Xcode fallback with finalized/local-only notes and credentials; inject migration/update failure.   | Stable identity, protected originals/pending state and recovery before any destructive reinstall. Prototype evidence cannot replace actual reader checks; no badge/background guarantee or silent archive downgrade. [Packaging][packaging], [persistence][persistence]. |
| Preserve required native accessibility and tools | Independently run the supported system input-preference/tool matrix, Scribble, VoiceOver, larger interface text and focus restoration on the intended iPad/OS.                       | Applicable Pencil effects, readable controls/available text and editable ink all pass. Unsupported tools/versions are explicit; no app-only gesture imitation or image-only excuse for available-text failure. [Input][input], [profiles][profiles].                     |
| Measure the declared scale and latency envelope  | Use 50,000 books/100,000 annotations plus specified Trash/conflict/replay loads, second-account isolation and twenty offline books; record actual reference environment and network. | All [conditioned targets][targets] are measured with at least thirty ordinary repetitions, p50/p95, failures and combined native/WebKit memory methodology. No small-dataset substitute or old single capture time as a percentile.                                      |
| Enforce every resource boundary safely           | Independently approach/cross each file/member/expanded-byte/pixel/DOM/drawing/manifest/transport/staging/recovery limit, timeout and quota.                                          | Work remains responsive/bounded or refuses with progress/cancel/recovery; no silent truncation, cropped ink, lowered fidelity, false save or automatic removal of chosen/protected data. [Negotiated limits][storage-bounds].                                            |

A mandatory correctness, ownership, preservation, anchoring, recovery or required-accessibility failure blocks daily use. Only documented minor cosmetic defects may remain after every required flow and declared variant passes. That rule does not make these unrun checks passed or authorize their execution now.
